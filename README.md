# Insurance Data Analysis & Reporting using Power BI and SQL Server

## 📌 Project Overview
This project focuses on analyzing insurance data using **Microsoft SQL Server and Power BI** to build an end-to-end, interactive reporting solution.  
The objective is to transform raw insurance data into meaningful insights related to **policies, claims, trends, and customer sentiment**, while simulating a real-world enterprise reporting environment.

The project demonstrates skills in **database integration, data profiling, visualization, automation, security, and sentiment analysis**.

---

## 🛠 Tools & Technologies Used
- Power BI Desktop  
- Power BI Service  
- Microsoft SQL Server (MSSQL)  
- Power Query  
- SQL  
- CSV / Excel Dataset  

---

## 📂 Dataset Description
The dataset contains insurance-related information such as:
- Policy details  
- Customer information  
- Claim status and amounts  
- Policy types and regions  
- Text-based feedback/reviews (for sentiment analysis)

The data was first imported into **SQL Server**, then connected to **Power BI** for analysis and reporting.

---

## 🔄 Project Workflow

### 1️⃣ Database Setup
- Installed and configured **Microsoft SQL Server**
- Created database and tables
- Imported insurance dataset into SQL Server

### 2️⃣ Data Connection
- Connected **Power BI Desktop** to SQL Server
- Loaded data using Import/Direct Query mode

### 3️⃣ Data Profiling & Validation
- Checked data types and column consistency
- Identified missing or incorrect values
- Ensured data quality before visualization

### 4️⃣ Dashboard Development
Created multiple visuals to analyze insurance data:
- **Card visuals** for KPIs (total policies, claims, approvals)
- **Bar charts** for category-wise analysis
- **Line charts** for trend analysis
- **Donut charts** for distribution insights
- **Matrix visuals** for detailed tabular analysis

### 5️⃣ Interactive Features
- Added **slicers** for dynamic filtering
- Implemented **drill-through filters** to navigate from summary to detailed views

### 6️⃣ Automation
- Published the report to **Power BI Service**
- Configured **scheduled data refresh** to automatically update dashboards

### 7️⃣ Security Implementation
- Created user roles in Power BI Desktop
- Implemented **Row-Level Security (RLS)** to restrict data visibility
- Tested and deployed RLS in Power BI Service

### 8️⃣ Sentiment Analysis
- Used **Power Query** to perform sentiment analysis on text feedback
- Classified sentiment as Positive, Negative, or Neutral
- Visualized sentiment insights in the dashboard

---

## 📊 Key Features
- End-to-end data analysis using SQL Server and Power BI  
- Interactive dashboards with slicers and drill-through  
- Automated data refresh in Power BI Service  
- Secure data access using Row-Level Security (RLS)  
- Sentiment analysis using Power Query  
- Business-focused KPIs and trend insights
